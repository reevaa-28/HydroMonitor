# HydroMonitor – AI-Based Hydropower Monitoring System

## About the Project
HydroMonitor is a web-based hydropower monitoring application developed using Python and machine learning. It provides simulated real-time sensor readings, monitors the operational condition of a hydropower plant, predicts power generation, and identifies potential abnormal conditions.

The project demonstrates how machine learning and a digital twin concept can be used to support hydropower monitoring and decision-making.

## Features
- Live simulated sensor readings
- Hydropower plant monitoring dashboard
- Power generation prediction
- Machine learning-based analysis
- Turbine condition monitoring
- Abnormal condition detection
- Interactive charts and visualizations
- Historical data monitoring
- Alert and warning system
- Digital twin simulation

## Technologies Used

## Machine Learning
The system uses machine learning models to analyze simulated operational data, estimate power generation, and support monitoring of hydropower plant conditions.

## Sensor Simulation
Since physical sensors are not connected, the application generates simulated sensor readings for demonstration purposes. These readings represent operational parameters such as water flow, hydraulic head, turbine speed, vibration, temperature, and power generation.

## Project Purpose
The purpose of HydroMonitor is to demonstrate the application of web development, database management, machine learning, and simulated sensor monitoring in the hydropower domain.
